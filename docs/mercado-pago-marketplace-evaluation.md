# Mercado Pago Marketplace / Split — avaliação

Split não está ativado. Uma evolução 1:1 exige decisão financeira, contábil e jurídica, onboarding OAuth de cada prestador, gestão de consentimento, reconciliação, estornos, chargebacks e titularidade fiscal. Antes de implementar, validar elegibilidade da conta, APIs oficiais vigentes, responsabilidades e plano de migração. O fluxo atual permanece inalterado; credenciais e taxas nunca devem ser inventadas.

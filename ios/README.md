# Estrutura iOS preparatória

Estes arquivos são templates auditáveis de permissões, Associated Domains e Privacy Manifest. O projeto Xcode gerado não foi falsificado: execute `npm install`, `npx cap add ios` e `npm run sync:ios` em macOS para criar/atualizar `ios/App/App.xcworkspace`, e então aplique os templates conforme `docs/ios.md`. O Bundle ID permanece centralizado em `config/app-config.js`.
